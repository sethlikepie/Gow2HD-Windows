### Ledger policy (CONTEXT)

- `estado=migrated` only when the **declared** (or midasm/weak — not here) path is
  what makes the fix re-lift-safe and A failed.
- `estado=redundant` when A already passes — **valuable honesty**; **does not**
  count toward XEN-05 ≥3 re-lift-safe fixes.
- Never write `migrated` without the re-lift grep proof.
- If both A and B fail → **do not** mark migrated; leave `todo`, fix TOML/detector
  or report. Forging accept by re-adding the patch is failure.

### Patch script behaviour

If `migrated` or `redundant`:

- Prefer making the patch **idempotent verifier**: if switch cases already match
  the oracle set, print OK and exit 0; only inject legacy body if verification
  fails (current 2a209c already leans this way — extend, do not regress).
- Or skip with a clear `SKIP: source of truth is switch_table / discovery` message.
- Do **not** delete the patch file in this phase unless apply-path inventory
  requires it; ledger state is the source of truth for migration metrics.
