### Contract (from 18-CONTEXT + XEN-03 + Xenon B1)

| Concern | Rule |
|---|---|
| Tool role | **New** sibling of the lifter — `tools/ps3_analyse.py`, **not** a lifter flag |
| CLI | `python tools/ps3_analyse.py &lt;ELF\|raw&gt; -o &lt;toml&gt; [--include-low]` |
| TOML entry | `[[switch_table]]` with `dispatch`, `default = "indirect"`, `cases` (list of targets or `{index, target}`), plus **`confidence`** (`"high"` / `"low"` or equivalent documented scale) |
| `dispatch` | Address of the **`bctr`** (or `bcctr`), **not** the preceding `mtctr` |
| Default filter | Write **only** `confidence=high` tables unless `--include-low` |
| Low confidence | With `--include-low`, write low tables (still tagged); **never** claim they are production-ready |
| No ELF in repo | Tests use synthetic words / temp files; never commit EBOOT |

### Heuristic v1 (must document limits in module docstring)

1. Scan for `mtctr rX` followed within **N** instructions by `bctr` / `bcctr` (N is executor discretion; pin it in a named constant + docstring).
2. Backtrack in the same window for `rlwinm` / `lwzx` (and the TOC/`lwz` base patterns already proven in `discover_jump_tables` where cheap to reuse).
3. Read table entries as big-endian words; keep targets that land in `.text` (or the synthetic text range in fixtures) and are 4-byte aligned.
4. Score `confidence`:
   - **high**: full chain present (mtctr + bctr + lwzx + validated ≥2 in-text targets), bound check / count plausible.
   - **low**: partial chain, or few/ambiguous targets — emit only with `--include-low`.
5. **Write limits explicitly**: false positives jump to garbage at boot; false negatives leave discovery/`patch_jumptable_*.py` as the safety net. Document that absolute vs offset tables, multi-TOC, and two-level PIC are partial in v1 if not fully shared with `discover_jump_tables`.

### Implementation guidance (discretion, not free invention)

- Prefer **importing** shared helpers from `ppu_disasm` / reusing the encoding builders pattern from `test_ppu_jumptables.py`.
- May call or factor shared decode logic with `discover_jump_tables` **if** it stays a clean import without turning the analyser into a second lifter CLI. Duplicating the minimum is acceptable; forking silently is not.
- Output must be loadable by `load_switch_tables` for the **consumer fields** (`dispatch`, `default`, `cases`). `confidence` is analyser metadata: either strip before production handoff (18-02) or leave as a key that the loader **ignores** (verify it does not raise — today `_parse_switch_table` only reads known keys).
- `default` always the literal `"indirect"`.
- Stdlib only for the test runner (same convention as other `tools/test_*.py`: asserts + `main()`, no pytest required).

### Minimum test cases (`tools/test_ps3_analyse_jtables.py`)

1. **Happy path high**: synthetic buffer with `cmplwi` + `lwz` base + `lwzx` + `mtctr` + `bctr` and a tiny BE table of ≥2 in-text targets → TOML has one `[[switch_table]]`, `dispatch` == bctr EA, cases cover those targets, `confidence` high (or filter keeps it without `--include-low`).
2. **bcctr path**: same as (1) but terminal is `bcctr` if the disassembler/decoder supports it; if not supported in v1, **document skip** and cover only `bctr` with an explicit "bcctr deferred" comment in the test file — do not silently pretend.
3. **rlwinm/lwzx backtrack**: fixture where index scaling is `rlwinm` before `lwzx`; detector still finds the table.
4. **Default filter**: craft a deliberately weak/partial chain that scores **low** → without `--include-low`, output has **zero** (or only high) tables; with `--include-low`, the low table appears tagged.
5. **Round-trip shape**: write TOML to a temp file; `load_switch_tables(path)` returns a `SwitchTable` whose `dispatch` and `cases` match (ignoring `confidence` if present).
6. **CLI smoke**: subprocess invoke of `ps3_analyse.py` with `-o` on a temp synthetic raw (or ELF-like buffer path the tool accepts) exits 0 and creates the file.
7. **No accidental midasm/switch lifter changes**: this plan must **not** modify `ppu_lifter.py` emission. If a shared helper is extracted, keep behaviour of `discover_jump_tables` covered by re-running `tools/test_ppu_jumptables.py`.
