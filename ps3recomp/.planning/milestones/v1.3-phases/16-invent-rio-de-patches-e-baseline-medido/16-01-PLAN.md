### `gen_migration_ledger.py`

**Entradas:**
- `PATCH_CATALOG.tsv` (classe/subclasse/marcador)
- directório de patches de build: `../gow2-recomp/recomp_mid_v2`
- directório monorepo: `games/gow2/recomp_mid_v2` (só para flag de divergência)
- opcional: ledger anterior (merge: preservar colunas humanas se o patch ainda existe)

**Saída:** `PATCH_MIGRATION.tsv` com:

Colunas **obrigatórias** (LEDG-01 / ROADMAP):
`patch`, `classe`, `alvo`, `ea`, `prioridade`, `aceite`, `estado`

Colunas **auxiliares recomendadas** (ordem livre desde que as 7 existam):
`subclasse_catalogo`, `so_no_build` (`1` se só existe no checkout de build),
`marcador` (do catálogo, se houver)

**Derivação (nunca pedir ao humano):**

| coluna | regra |
|---|---|
| `patch` | nome do ficheiro `patch_*.py` (universo = união build ∪ monorepo, mas **linha obrigatória** para cada ficheiro em build; monorepo-only se existir fica com nota no header) |
| `classe` | mapa de 16-RESEARCH: PROBE+orfao-sem-fonte→`OBSOLETE`; PROBE→`PROBE`; FUNCIONAL+opd→`OPD`; FUNCIONAL→`CORRECTNESS`. Se o patch ainda não está no catálogo (não deveria após Task 1), falhar ruidosamente |
| `ea` | heurística, nesta ordem: (1) `func_XXXXXXXX` / `0xXXXXXXXX` no nome do ficheiro; (2) primeiro `void func_XXXXXXXX` ou `FUNC_SIG`/`SIG =` no corpo; (3) `-` se nenhum |
| `alvo` default | `PROBE`→`keep-probe`; `OBSOLETE`→`delete`; resto → vazio (a preencher na 16-02) |
| `prioridade` default | vazio (PROBE sem prioridade — CONTEXT); resto vazio |
| `aceite` default | vazio |
| `estado` default | `todo` |

**Cabeçalho `#` obrigatório** (números **medidos na corrida**, não copiados):
```
# PATCH_MIGRATION.tsv -- ledger de migracao patch→mecanismo (Fase 16 / LEDG-01)
# regenerar esqueleto: .venv/bin/python3 games/gow2/lift_baseline/gen_migration_ledger.py
# COLUNAS HUMANAS (nao sobrescrever no regen se --merge): alvo, prioridade, aceite, estado
# COLUNAS DERIVADAS: patch, classe, ea (heuristica), subclasse_catalogo, so_no_build
# baseline contagens (AAAA-MM-DD):
#   patch_*.py monorepo (games/gow2/recomp_mid_v2) = N_MONO
#   patch_*.py build    (../gow2-recomp/recomp_mid_v2) = N_BUILD
#   PATCH_CATALOG linhas de dados = N_CAT
#   divergencia build-monorepo = N_BUILD - N_MONO (declarada; reconciliar subtree FORA de escopo)
# baseline verify/smoke: (preenchido no plano 16-03) rc=… st620_max=… sticky=… oob_pos_tls=…
# mapa classe: ver 16-RESEARCH.md / comentario abaixo
```

**CLI sugerida:**
```bash
.venv/bin/python3 games/gow2/lift_baseline/gen_migration_ledger.py \
  [--catalog games/gow2/lift_baseline/PATCH_CATALOG.tsv] \
  [--build-dir ../gow2-recomp/recomp_mid_v2] \
  [--mono-dir games/gow2/recomp_mid_v2] \
  [--merge games/gow2/lift_baseline/PATCH_MIGRATION.tsv] \

```
