### Contract (from 17-CONTEXT + XEN-01)

| Field | Emission |
|---|---|
| `name` | call `gow2_midasm_<name>(ctx);` — **exact** prefix `gow2_midasm_`, name as in TOML (no sanitizing beyond valid C identifier; tests use `TestHook`, `AfterHook`, `ReturnHook`) |
| `address` | guest EA of the instruction |
| `after_instruction=false` (default) | emit call **before** the translated line for that EA |
| `after_instruction=true` | emit call **after** the translated line |
| `return=true` (Python: `returns`) | emit `return;` **immediately after** the hook call (same before/after placement as the hook) |
| `jump_address` | **not implemented** in v1 — if non-null, print a clear Warning to stderr and **do not** emit a branch; never invent a `goto` |
| no `--config` / empty hooks | **zero** midasm strings in output |

ABI: `void gow2_midasm_<Name>(ppu_context* ctx);` — type is **`ppu_context*`** (what the lifter already emits), **not** `PPUContext*`.

### Hook does not replace the instruction

Always emit the translated insn as well (unless the function is an HLE stub path that never walks insns). `return=true` may leave dead code after the return; that is fine for v1.

### Insertion point (recommended)

In `lift_function`, inside the `for insn in range_insns:` loop, around the existing `_translate` call (~697–699):

```python
# before
for h in self._midasm_at(insn.addr, after=False):
    func.body_lines.append(f"    gow2_midasm_{h.name}(ctx);")
    if h.returns:
        func.body_lines.append("    return;")
c_line = self._translate(insn, func)
if c_line:
    func.body_lines.append(f"    {c_line}")
# after
for h in self._midasm_at(insn.addr, after=True):
    func.body_lines.append(f"    gow2_midasm_{h.name}(ctx);")
    if h.returns:
        func.body_lines.append("    return;")
```

Label emission (`loc_…:`) stays **before** before-hooks so labels still mark the real block entry.

Unit tests may use a buffer where the hook EA is present; add one negative test that an orphan EA fails the CLI (or the public API used by the test harness).
