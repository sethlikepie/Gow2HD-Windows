### I4/I5 ids for delta

Map `audit_boundaries` JSON findings to opaque ids suitable for
`baseline_delta.py`:

| Class | Id shape (suggested; pin in code + test) |
|---|---|
| I4 | `I4:&lt;oracle_name&gt;:&lt;addr&gt;` |
| I5 | `I5:&lt;oracle_name&gt;:&lt;addr&gt;:&lt;tipo&gt;` where `tipo` is one of `extende-seguro` / `extende-funde` / `encurta` |

**Gate policy (CONTEXT + adoption plan):**

- **In baseline / gate set for FAIL-on-new:** at minimum **all I4** and **I5
  `extende-seguro`** (and preferably all I5 kinds so a new `encurta` is also
  visible — if you include all I5, document it; if you exclude `extende-funde`
  from the *gate* set, still **print** counts for funde).
- **Never** fail on absolute count of I4/I5. Only `baseline_delta` "new ids".
- Resolved findings (in baseline, absent now) are informative only (rc stays 0).

Implementation options (executor discretion; behaviour mandatory):

1. Call `audit_boundaries` with `--oracle` + `--json`, then map findings → ids
   in `oracle_manifest.py` / a small helper; **or**
2. Add a thin flag on `audit_boundaries` that emits `{"ids":[...]}` directly —
   only if it does not break existing CLI consumers.

Do **not** add absolute `--gate I4,I5` as the accept path for `verify_lift`

### Env contract

| Variable | Default | Effect |
|---|---|---|
| `VERIFY_ORACLE` | unset / empty / `0` | **No** oracle step. Identical to today (parity + MANIFEST + bounds I1/I3 only). |
| `VERIFY_ORACLE=1` | — | After the three existing steps (or as a fourth `run_step`), run the oracle path. |

Optional overrides (document in script header):

| Variable | Default |
|---|---|
| `PS3_GHIDRA_OUT` | `$GOW2_ROOT/ghidra_out` then fallbacks documented in header |
| `PS3_ORACLE_FUNCTIONS` | `$PS3_GHIDRA_OUT/functions.json` |
| `PS3_ORACLE_MANIFEST` | `$PS3_GHIDRA_OUT/MANIFEST.json` |
| `PS3_ORACLE_BASELINE` | `$BASE/ORACLE_BASELINE.json` |

### Oracle step algorithm

1. Resolve `functions.json` + `MANIFEST.json` under `PS3_GHIDRA_OUT`.
2. `oracle_manifest.py check --manifest … --elf "$ELF"` — fail if absent/stale.
3. Run `audit_boundaries.py "$FUNCTIONS" --elf "$ELF" --oracle "$PS3_ORACLE_FUNCTIONS" --json "$TMP/oracle_current.json"` (no absolute `--gate I4,I5`).
4. Map findings → `{"ids":[…]}` → `$TMP/oracle_current.ids.json`.
5. `baseline_delta.py $TMP/oracle_current.ids.json $PS3_ORACLE_BASELINE --label oracle_i4_i5`.
6. Step rc feeds `run_step "oracle_ghidra" …` like the other steps. Overall exit is OR of all steps.
