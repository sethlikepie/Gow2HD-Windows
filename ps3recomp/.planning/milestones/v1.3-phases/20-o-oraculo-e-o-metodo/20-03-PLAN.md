### Create `docs/GHIDRA_MCP_SETUP.md`

Required content:

1. **Status**: optional / soft requirement for v1.3 Track R.
2. **Pinned choice**: name of MCP server (e.g. LaurieWired/GhidraMCP or currently
   maintained fork) + **version pin** (tag, commit, or release number known at
   write time). If multiple candidates, pick one primary and list alternates
   as non-goals.
3. **Host requirements**: Ghidra major version (11+/12), JDK (21 as used by
   `analyze_eboot_ghidra.sh`), OS note for macOS/arm64 primary.
4. **Install outline** (no secrets):
   - Ghidra extension install steps (high level).
   - How the user registers MCP in **local** client config (`~/.claude`,
     Claude Desktop, Grok, etc.) — example JSON **with placeholders**, never
     real tokens.
5. **Allowed tools** (whitelist mindset):
   - decompile / get function
   - xrefs / callers
   - rename / annotate (comment) **in the Ghidra DB only**
6. **Forbidden tools / behaviours**:
   - export whole program rewrite
   - blind binary patch
   - generate product C/C++ for `runtime/` / `libs/` / lift chunks from MCP alone
   - replace static `ghidra_out` as the oracle for `VERIFY_ORACLE`
7. **Parity procedure**:
   - Pick a known GoW2 EA (e.g. from playbook session or `0x000CE03C` / wall EA).
   - Run `ghidra_lookup.py ghidra_out EA --callers` → save sorted caller list.
   - Ask MCP/agent for callers of the same EA.
   - Compare sets; document match or diff.
8. **Failure mode**: if install is interactive-only, headless-blocked, or
   flaky → write `wont` section template for SUMMARY.
