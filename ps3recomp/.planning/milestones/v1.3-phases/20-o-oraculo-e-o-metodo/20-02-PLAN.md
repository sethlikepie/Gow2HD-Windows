### Run a real session (not a fictional write-up)

Minimum bar for RE-02:

1. State the wall question in one sentence.
2. List anchors (EA + Ghidra name if resolved + log tag).
3. Run **at least** `ghidra_lookup` for the EA and `--callers` (or document
   MCP parity later in 20-03). Paste **truncated** output (addresses/names only;
   do not dump megabytes of decompile into git).
4. Write **≥2 hypotheses** with discriminating experiments.
5. Execute experiments **or** prove with existing logs that a hypothesis is
   already refuted/supported. Evidence levels labelled.
6. Verdict: **still open** / **partial** / **fixed** — honest. Prefer open with
   two refutations over a cosmetic "fixed".
7. List next experiment for whoever resumes (Phase 11).
