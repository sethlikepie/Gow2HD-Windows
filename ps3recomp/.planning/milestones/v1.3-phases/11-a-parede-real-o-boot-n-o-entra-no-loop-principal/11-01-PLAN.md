Confirm with `python3 tools/show_func.py 0x0041FF70 --asm --elf ../gow2-recomp/EBOOT.ELF --functions ../gow2-recomp/functions.json --max 90` that the instruction at EA 0x0042003C is still `lwz r27, 0x88(r28)`, immediately preceded by `rldicl r28, r26, 0, 32` (0x0042002C) and `lwz r0, 0x70(r28)` / `beq cr7, 0x41FFE8` (0x00420030/0x00420038 — the "has-child" gate), and immediately preceded further back by the two flag-filter branches at 0x0042000C (`bne cr7, 0x41FFE8` on `flags & 0x10`) and 0x00420018 (`bne cr7, 0x4201D0` on `flags & 3`). These four checks are D-11.2's "the two flag filters" plus the has-child gate that must all pass before r28/piVar8 is a live candidate — this planning session verified this exact chain with the same tool against the same EBOOT.ELF; re-confirm the bytes have not moved before anchoring on them.

### Add the hook (per D-11.2)

Declare a fourth `[[midasm_hook]]` in games/gow2/config/gow2_recomp.toml, name `OuterWalkSubtagCensus`, address = 0x0042003C — inside the existing "SONDA E1" comment block's family (same walk investigation, different function: the OUTER walk 0x0041FF70, not the inner push 0x0041F700). Add a short header comment (mirroring the existing three) stating: NOT a fix, gated by PS3_OUTER_SUBTAG_CENSUS, OFF by default, read-only (no ctx->gpr / memory writes), and citing this plan + D-11.2.

Implement `void gow2_midasm_OuterWalkSubtagCensus(ppu_context* ctx)` in gow2_midasm_hooks.h (declaration) and gow2_midasm_hooks.cpp (body), appended after the existing TypewalkPop hook, same `extern "C"` block or a new one immediately after — match whichever the existing file already does for grouping.

At the hook's anchor point (before 0x0042003C executes), `ctx->gpr[28]` holds the registration-wrapper pointer ("piVar8" in the Ghidra C) and has already passed both flag filters and the has-child gate. The hook must, read-only:
- Guard `gow2_ea_ok(ctx->gpr[28] + 0x88)` before reading; skip (still counting nothing, return) if not ok.
- `h_child = vm_read32(gpr28 + 0x88)` — this is exactly what the guest instruction at 0x0042003C is about to load into r27; the hook computes it itself and does not write gpr27, so it observes without altering the translated instruction that follows.
- Guard `gow2_ea_ok(h_child + 4)` before reading `w0 = vm_read32(h_child + 4)`.
- `low16 = w0 & 0xFFFF`, `subtag = (w0 >> 16) & 0xFFF` (same construction as the deserializer and as the E1 push hooks — do not re-derive, copy the established formula).
- D-11.2's predicate: this node counts toward the census total when it passed the two flag filters and the has-child gate (guaranteed by the anchor point) AND `subtag != 1`.
- On a match: increment a static census counter; if the (low16, subtag) pair has not been seen before (cap at 16 distinct pairs — the outer walk has ~176 total iterations, nowhere near E1's 179M, so no aggregation table is needed, a small seen-set suffices), emit one `[PS3T]` line via `ps3_trace_emit(PS3_TS_CHECKPOINTS, "func_0041FF70", "OUTER_SUBTAG_MATCH", ...)` with w0, h_child, low16, subtag, and the piVar8 wrapper pointer (ctx->gpr[28]).
- Also maintain, unconditionally on every call (not gated on the D-11.2 predicate): a running total-visits counter and the tab-base control read `ctx->gpr[24]` (C1-equivalent: tab base must read 0x00868D48 at every call — this register is loaded once at function entry and stays live through the whole walk per the disassembly).
- On the FIRST call, emit an `OUTER_SUBTAG_ALIVE` line unconditionally (this is the E3-equivalent control probe: without it, a silent zero cannot be told apart from "the hook never compiled/never got reached").
- The gate function `gow2_outer_subtag_census_on()` follows the exact `static int on = -1; getenv("PS3_OUTER_SUBTAG_CENSUS"); ...` pattern already in this file. With the env var unset, the hook must read one cached int and return — zero other work, zero bytes to stderr (G2, proven by control probe C3 below).
- On a final/periodic dump (reuse the existing `tw_time_due()`-style 5-second periodic check already in this file, or a simpler one keyed off this hook's own call count if simpler): emit a summary line `OUTER_SUBTAG_CENSUS_SUM` with the running total count, the number of distinct (low16,subtag) keys seen, and the tab-base-mismatch counter. Do this periodically (not only at the end) because the boot is killed by `kill -TERM` (G6) — no `atexit` runs.
