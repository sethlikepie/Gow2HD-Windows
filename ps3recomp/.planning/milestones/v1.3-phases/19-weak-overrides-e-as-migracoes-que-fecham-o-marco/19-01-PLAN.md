### Symbol scheme (pin this — ROADMAP + 19-CONTEXT; macros in older Xenon notes may invert weak placement)

| Symbol | Linkage | Role |
|---|---|---|
| `__imp_func_XXXXXXXX` | **strong** | Lifted body (implementation) |
| `func_XXXXXXXX` | **weak** (when emission on) | Thin wrapper: calls `__imp_func_XXXXXXXX(ctx)` |
| Host `func_XXXXXXXX` | **strong** | Override that **wins** over the weak wrapper at link |

- Use the **same C++ linkage** the lifter already emits for `void func_*(ppu_context*)` — **not** `extern "C"` (midasm hooks comment on mangling of `func_002C0508` is the measured precedent).
- `runtime/ppu/ppc_hooks.h`:
  - Include / forward-declare `ppu_context` consistently with `runtime/ppu/ppu_context.h`.
  - Clang (`#if defined(__clang__)`): weak attribute on the **wrapper** macro path used for `func_*`; strong for `__imp_*` body.
  - Non-Clang: both strong; document that override requires link-order / not supported as first-class on that toolchain.
  - Do **not** copy the inverted macro sketch from the old A4 plan blindly — measure with `nm` that the **wrapper** is weak and the **body** is strong.

### Gate: emission OFF by default

Recommended contract (executor may refine names; behaviour is mandatory):

1. Master gate: CLI `--emit-weak-wrappers` **and/or** TOML key under `[main]` e.g. `emit_weak_wrappers = true` (parse in `recomp_config.py`). **Default false.**
2. Selection: emit wrappers **only** for functions whose start EA is listed in `[[functions_override]]` (`address` already parsed; `size` may be validated or ignored with a comment — do not invent a second list schema).
3. If gate is true and the override list is empty: print a clear **Warning** and emit **zero** wrappers (safe empty), not "all functions" (doubling every symbol on a full GoW2 lift is a cost bomb; CONTEXT asked to measure before "all").
4. Without the gate: **byte-identical** output to current lifter on a synthetic fixture (golden `diff`, only allowed normalize: `/* lifter-rev */` if present).

### Emission shape (conceptual)

```c
void __imp_func_0000ABCD(ppu_context* ctx) {
    /* lifted body unchanged */
}
__attribute__((weak)) void func_0000ABCD(ppu_context* ctx) {
    __imp_func_0000ABCD(ctx);
}
```

- Forward declarations in the preamble must stay consistent (declare both or only `func_*` as today — pick one and test linkability of inter-function `bl` which uses `func_*` names).
- `function_table` entries continue to point at `func_*` (the overridable name), never at `__imp_*`.
- Direct calls inside the lift (`func_OTHER(ctx)`) keep calling `func_*` so an override of a callee is visible to callers.
- Propagate override-EA set through `_worker_init` / `_WORKER_STATE` / `_worker_lift` / `_parallel_lift` **exactly like** midasm / invalid_instructions. Silent drop under `-j` is a phase failure.

### Loud failure

- If `[[functions_override]]` lists an address that is **not** a lifted function start in this run: fail with non-zero exit or hard `Error:` listing orphans (same spirit as midasm orphan EA). Silent no-op is forbidden.

### `tools/test_weak_override_symbols.py` — minimum cases

Stdlib asserts + `main()`, no pytest required. Prefer temp dirs.

1. **Golden no-flag**: same synthetic buffer lifted with and without weak emission → `diff` of function bodies empty (after optional rev-line normalize).
2. **Shape with flag + override entry**: output contains both `__imp_func_…` and weak `func_…` calling it; body of `__imp_` matches the no-flag body of `func_…` (modulo renames).
3. **Flag on, empty override list**: zero `__imp_func_` substrings + warning path covered (or documented if warning is CLI-only).
4. **Orphan override EA**: CLI/API fails loudly.
5. **Worker propagation**: hooks/override set survives `_worker_init` path (mirror midasm test).
6. **Real link measurement (the Apple ld risk)**:
   - Write a tiny `.cpp` with a weak `func_test` that returns 1 and a strong `func_test` that returns 2 (or use the emitted pair).
   - Compile+link with the **same clang++** the project uses on this Mac.
   - `nm` the binary: weak symbol present when no strong override; with strong override, the winning text is the strong one (or runtime call returns 2).
   - If strong does **not** win: test **FAILS with a clear message** — do not paper over; SUMMARY must declare the mechanism unviable and stop migrations (19-CONTEXT: measure, do not invent).
7. **Mutation**: force the test to expect wrong return / strip weak attribute → assertion fails (proves the test is discriminative).
