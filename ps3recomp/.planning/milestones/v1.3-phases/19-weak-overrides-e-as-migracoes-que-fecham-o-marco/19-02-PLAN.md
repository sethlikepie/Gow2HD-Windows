   - Pick a **non-critical** function that is easy to re-lift with `[[functions_override]]` — either:
     - (A) a tiny always-called function overridden to call `__imp_func_…(ctx)` (identity; proves win without behaviour change), or
     - (B) a dedicated probe symbol only present under a test lift — if (A) is safer for production smoke, prefer (A).
   - Identity override that merely calls `__imp_*` is ideal for smoke: proves link selection without changing boot behaviour.

### build_macos.sh

Mirror the midasm block carefully:

1. Compile `hooks/gow2_func_overrides.cpp` → `$LIFT/gow2_func_overrides.o` with `clang++ -std=c++20` and the same `INC` / `-I hooks`.
2. **Anti-duplicate guard** must detect a **definition** of `func_XXXXXXXX` in the lift (signature + `{`), not a prototype and not a call. The midasm guard's two-regex pattern is the template — adapt for `func_[0-9A-Fa-f]{8}` **only if** the override is also emitted as a strong definition in a patched lift (normally the lift only has weak wrappers, so the guard should **not** fire and the host `.o` must compile). Document the measured case.
3. Add the `.o` to the final link line next to `gow2_midasm_hooks.o`.
4. If Apple ld dead-strips an unused overrides object when the pilot is not referenced: use `__attribute__((used))` or ensure the lifted weak wrapper references the same symbol name (link resolves at final link of `func_*`).
