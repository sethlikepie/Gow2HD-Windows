### Why weak (not midasm)

The pad **wraps** the natural guest body (`setjmp` → body → abort path with
`cellVdec_stop_all_for_play_abort` + freelist rebuild). A `[[midasm_hook]]` runs
**beside** an instruction and cannot enclose the body. That is WINDOWS #8.

### Target design

1. Declare `[[functions_override]]` for `0x000CE03C` (+ emit weak flag on).
2. Host strong `void func_000CE03C(ppu_context* ctx)` in `gow2_func_overrides.cpp` that:
   - Keeps wait-idle behaviour (call existing `gow2_midasm_Ce03cWaitIdle(ctx)` **or** fold the same logic — one source of truth, no double pump).
   - Arms `g_ce03c_play_abort` / `setjmp` around the natural body.
   - Natural body: prefer calling `__imp_func_000CE03C(ctx)` so a re-lift updates the guest portion automatically; if `__imp_` already includes midasm emission at EA, **avoid double wait-idle** (either strip midasm for CE03C when full override is live, or have `__imp_` be pure guest-only and keep wait-idle only in the override). **Measure and pick one**; document the choice.
   - Abort branch: same freelist / TOC restore semantics as the patch (verbatim behaviour, not a rewrite for style).
3. Legacy `patch_ce03c_introseq_block.py`: become no-op / skip / ALREADY when weak+override is the source of truth on config lifts; keep file for production lifts that still need it until promote. Do not delete unless proven safe.
4. Ledger: keep `estado=migrated` for CE03C rows; add a header note that pad is now covered (or still residual). Completing the pad does **not** invent a third CORRECTNESS line by itself.
5. WINDOWS #8 → `fixed` only if re-lift **without** the patch still contains the abort pad (marker log or structural proof). If residual patch is required: leave open or fix with "residual pad patch" path and write the reason.

### Proof

- Re-lift **without** `patch_ce03c_introseq_block.py`, with `--config` + weak:
  - `__imp_func_000CE03C` + weak wrapper present
  - host override in `gow2_func_overrides.cpp` linked
  - marker strings that only exist on host (`[INTROSEQ] CE03C Play aborted` / freelist rebuild) live in host TU, not in lift (or greppable as intended)
- Locate by **function**, not loose text (Phase 18 lesson).

### Fallback (honest)

If full weak wrap is too large / breaks smoke: residual minimal patch **only for the pad**, documented in WINDOWS and ledger — Phase 19 still can close XEN-05 via other CORRECTNESS migrations below.
