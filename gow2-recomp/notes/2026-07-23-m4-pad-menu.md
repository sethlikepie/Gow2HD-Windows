## Quick RE (≤30 min, sem rabbit hole)

1. **NID/HLE:** `cellPadGetData` registado (`0x8B72CDA1` / `0x8B72CDA5`) e linkado
   em `boot_gow2` (`_cellPadGetData` presente via `nm`).
2. **Autostart path:** só em `cellPadGetData` quando port desligado + env set, e
   conexão virtual em `cellPadGetInfo2`. Sem call guest → zero efeito.
3. **Porque não há poll pós-menu-mode:** mesma classe M3 — guest **abandona** o
   path de present/frame flip ao abrir WAD (`SetFlip_after_R_Perm=0`); o poll de
   pad do movie/menu loop vive no frame path que não reentra. Não é bug de
   wiring do autostart; é **pré-condição de frame loop** falhada.
4. **Não encontrado nesta janela:** caller guest estático do 1º GetData pós-title
   (exigiria RE do import table + xref no ELF; deferido — não desbloqueia sem flip).
